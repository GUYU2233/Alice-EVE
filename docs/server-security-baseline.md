# 服务端安全基线（公开版）

> 本文件只描述可公开的安全原则与验收项，不包含真实 IP、域名、端口、SSH 用户、数据库 DSN、密钥、证书、Cloudflare 标识或生产路径。

## 目标

服务端采用“默认拒绝、最小权限、纵深防御、可审计、可恢复”的生产基线。安全配置不从 GitHub 仓库直接加载，生产值由服务器本地 Secret 管理系统或受控部署流水线注入。

## 网络边界

- 公网只暴露必要的 HTTPS 入口；应用进程仅监听 loopback 或私有网络。
- PostgreSQL、管理端口、调试端口和内部指标端口不允许公网访问。
- 反向代理执行 TLS、请求体上限、连接/请求超时、基础安全响应头和受控 Origin 校验。
- Cloud/WAF 规则、源站访问策略和真实拓扑保存在私有运维仓库，不提交公开仓库。
- 防火墙采用默认拒绝，仅允许已核准的入口；变更需要备份、审批和回滚方案。

## 身份与凭证

- 设备访问令牌使用短期凭证、轮换和撤销；服务端只保存不可逆摘要或受控密钥存储引用。
- 管理员使用独立账号、强 MFA、最小角色权限；禁止共享 root/管理员密码登录。
- 禁止把 EVE Token、数据库密码、OAuth client secret、JWT 签名密钥、私钥或备份密钥写入仓库、日志或模型上下文。
- 生产 Secret 通过 systemd credentials、云 Secret Manager 或等价的受控注入方式提供，禁止通过命令行参数传递。

## API 与应用层

- 所有外部输入执行 schema、长度、深度、枚举和内容类型校验。
- 按账号、设备和资源所有权做服务端授权；不能仅信任请求中的 deviceId、userId 或 recipient。
- 对配对、登录、OAuth callback、消息发布、ACK 和管理接口分别限流；失败响应不暴露内部路径、SQL、堆栈或凭证。
- 使用幂等键和重放保护；敏感操作记录审计事件。
- 对更新包执行签名/哈希校验，客户端只从固定的受信发布源下载。
- Agent 对话按账号和设备隔离；模型只能访问明确授权的摘要工具，不接触 Token、原始凭证或未授权私有数据。

## 主机与运行时

- 服务使用专用非 root 用户运行，文件系统和 systemd 权限最小化。
- 启用进程自动重启、资源限制、只读路径/临时目录隔离（在兼容性允许时）。
- 操作系统、安全依赖和反向代理按维护窗口打补丁；保留最近变更记录。
- SSH 仅允许密钥登录和受控来源，禁用密码登录、root 远程登录和不需要的转发能力；变更前必须确认不会失去现有管理通道。
- 启用入侵尝试封禁、登录审计、时间同步和磁盘空间告警。

## 数据库与备份

- 数据库仅接受本机/私网连接；应用数据库账号不得拥有超级用户权限。
- 迁移采用可审计、可回滚的版本；生产迁移前执行备份和恢复演练。
- 备份加密、限制访问、设置保留期，并定期验证可恢复性；备份不放入 Git。
- 按账号/设备隔离私有数据，删除、导出和撤销流程可审计。

## 监控与响应

- 记录 request id、账号/设备标识的不可逆或脱敏形式、路由、状态、延迟和限流结果；严禁记录 Authorization、Token、Cookie 和私密消息原文。
- 监控异常登录、配对失败突增、429/5xx、数据库错误、磁盘/内存和证书到期。
- 发生疑似泄露时先撤销/轮换凭证，再保全日志和备份，最后修复入口；不得在公开 issue 中粘贴敏感日志。

## 发布前验收

- [ ] 公开仓库扫描未发现凭证、私钥、真实环境文件和生产拓扑细节。
- [ ] 生产配置来自私有运维位置，且权限和轮换责任明确。
- [ ] 仅 HTTPS 公网入口可达，应用/数据库管理端口不可达。
- [ ] 身份、所有权、限流、重放、CORS/Origin 和安全响应头测试通过。
- [ ] 更新包签名/哈希和回滚测试通过。
- [ ] 备份恢复、凭证撤销、日志告警和应急联系人演练通过。
