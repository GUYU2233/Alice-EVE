# Alice-EVE Desktop Design System

## Direction
A focused intelligence command desk: dark navy workspace, blue operational actions, mint confirmation states, amber attention states, compact data-dense cards, and clear typography. The desktop app should feel like a calm professional monitoring tool rather than a game dashboard.

## Tokens
- Canvas: #080d18
- Surface: #111a2b
- Raised surface: #162238
- Inset: #0b1424
- Border: #263652
- Text: #e8edf7
- Muted: #8c9ab1
- Primary: #4d8dff
- Positive: #72d8ae
- Warning: #e3a64d
- Danger: #ed7886
- Radius: 8px controls, 12px cards, 20px status pills
- Spacing: 8 / 12 / 16 / 24 / 32
- Font: system UI; monospace for codes and raw Intel

## Interaction
Use explicit labels, disabled states, inline feedback, and empty states. Keep primary actions visible above the fold. Avoid decorative gradients and avoid hiding connection state.
